# 部署

服务需要 Node.js 20 或更新版本。首次启动没有登录凭据时，会进入 ClawBot 扫码登录；凭据保存在 `data/`。

## 本地运行

```bash
git clone https://github.com/JHPatchouli/clawbot-roleplay.git
cd clawbot-roleplay
npm install
npm start
```

运行数据、日志和登录凭据位于 `data/`。日志文件是 `data/server.log`。

## Docker Compose

在仓库目录创建 `.env`，至少填写一种容器登录方式：

```bash
SSH_AUTHORIZED_KEYS="ssh-ed25519 AAAA... you@host"
```

也可以改用 `SSH_ROOT_PASSWORD`。然后启动：

```bash
docker compose up -d --build
docker logs -f clawbot
```

默认端口只绑定到宿主机的 `127.0.0.1`：

| 宿主机端口 | 容器端口 | 用途 |
|---|---|---|
| 2222 | 22 | 容器 SSH |
| 8080 | 8080 | 扫码登录页 |

登录页不直接对公网开放。通过 SSH 隧道访问：

```bash
ssh -L 8080:127.0.0.1:8080 -p 2222 root@127.0.0.1
```

隧道建立后打开 `http://127.0.0.1:8080`。

## VPS

`deploy/vps-setup.sh` 输出中文，`deploy/vps-setup.en.sh` 输出英文；两个脚本执行相同的部署步骤。首次执行需要仓库地址和 SSH 公钥：

```bash
REPO_URL="https://github.com/JHPatchouli/clawbot-roleplay.git" \
SSH_PUBKEY="ssh-ed25519 AAAA... you@host" \
bash deploy/vps-setup.sh
```

常用参数：

| 变量 | 默认值 | 作用 |
|---|---|---|
| `APP_DIR` | `/opt/clawbot` | 代码和数据目录 |
| `BRANCH` | `main` | 拉取的分支 |
| `SSH_BIND` | `127.0.0.1` | 容器 SSH 的宿主机绑定地址 |
| `SSH_PORT` | `2222` | 容器 SSH 的宿主机端口 |
| `LOGIN_PORT` | `8080` | 登录页的宿主机端口 |
| `DEV` | `1` | `1` 挂载源码并热重载；`0` 使用镜像内代码 |

`SSH_BIND=127.0.0.1` 时，容器 SSH 只能从 VPS 本机访问。需要公网入口时改为 `SSH_BIND=0.0.0.0`，并用防火墙限制来源地址。脚本会把生效参数记入 `data/deploy.env`，下次执行时继续使用。

部署完成后：

```bash
docker logs -f clawbot
ssh -p 2222 root@127.0.0.1
```

公钥保存在宿主机的 `data/ssh/authorized_keys`。新增公钥后重新执行部署脚本即可写入容器。
